## 0. 三条主线（全课反复回扣）

1. **AFOSM 与 FORM 是同一个设计点。** 站台 4 在 X 空间沿 α 射线找边界，站台 5 在 U 空间做"切线→垂足"；路径不同，收敛到同一个 `β = 2.108`、`Pf = 1.750%`。站台 4 的对比卡直接标 `≡ 同一设计点`。
2. **MVFOSM 的 β 随写法变。** 同一失效面 `R = S`：写成 `R − S` 得 `β = 3.000`，写成 `R/S − 1` 得 `β = 2.080`；主例题的等价写法 `g₂ = X₁²/(2X₂) − 1` 得 `β = 1.714`。FORM 对这些写法**都是** `2.108 / 3.000`——这是方法是否具有不变性的分水岭。
3. **SORM 只改 Pf 的换算。** `β` 仍是 FORM 的 `2.108`，不重新找验算点；加一个曲率 `κ = 0.0612`，把 `Pf` 从 `1.750%` 修正到 `1.647%`（精确 `1.623%`）。

> 三条主线分别落在站台 4/5、站台 3（+ 站台 2 小表）、站台 6。收尾时回到站台 8 的对比表再说一遍。

## 3. 45 分钟逐段脚本

### 3.1 0–3 min｜站台 0 · 总览

**时间**：0–3 min（3 min）
**站台**：0 · 总览——"同一道题，为什么不是一个答案？"
**点击路径**：打开页面即在站台 0（任何时候按 `0` 回来）。先指"失效概率对比"条（log 轴），再指 6 张方法卡；点任意卡片可跳到对应站台。右上角"算法地图"按钮打开方法谱系伪代码。

**讲解要点**：

1. 同一道题、同一组随机变量，六个对象给出 **4.80% / 1.75% / 1.75% / 1.65% / 1.63% / 1.62%**（依次是 MVFOSM / AFOSM / FORM / SORM / MC / 精确）。最大差约 3 倍——不是算错，是假设不同。
2. 差异来自三个开关：**在哪儿线性化**（均值点 / 验算点）、**把边界当什么形状**（直线 / 抛物线 / 不假设）、**用多少样本**（蒙特卡洛）。
3. 页面地图：X 空间（斜椭圆、相关）→ U 空间（同心圆、β = 距离）→ 线性化（均值点 / 验算点）→ Pf（Φ(−β) 或模拟）。

**预期数字**：

- 方法卡：MVFOSM `1.664 / 4.80%`；AFOSM `2.108 / 1.75%`；FORM `2.108 / 1.75%`；SORM `2.108 / 1.65%`；MC `1.63%`（默认参数下是**参考** N = 4×10⁶）；精确 `1.62%`。
- 对比条是 **log 轴**，刻度 0.1% / 1% / 10%；下方 callout 写的就是"4.80% 与 1.62% 的差别不在算术"。

**常见问题**：

- **"AFOSM 和 FORM 为什么一模一样？"** → 同一设计点的两种走法，站台 4/5 分别演示（页面标 `≡`）。
- **"MC 我没抽，怎么已经有数？"** → 默认参数下显示预置的参考值（4×10⁶ 样本，行内标"参考 N=4×10⁶"）；**改任何参数这一行就消失**，要去站台 7 现场抽样。

> 🎯 **让学生先猜**：只读对比条，问"最大和最小差几倍、你信哪个？"先不给答案。

### 3.2 3–9 min｜站台 1 · 变量与变换

**时间**：3–9 min（6 min）
**站台**：1 · 变量与变换——"把'最可能'变成'最近'"
**点击路径**：按 `1`（或点左栏）。右侧四个步骤条目，或画布右上 `←` `→`（标签 `1 / 4`），从 1/4 走到 4/4；点 `播放` 可自动走完（每步 1.05 s、白化步 1.25 s 的仿射变形动画）。二步起会画 **β 等概率椭圆/圆** 和切点 x* 的 FORM 切线。右下"变换方式"切一次 **Cholesky ↔ PCA**。停在 2/4 或 3/4 时拖右栏 `ρ` 滑块（如 0.5 → 0），看斜椭圆变成正圆。

**讲解要点**：

1. X 空间里"离均值近"不等于"最可能失效"：两个分量的单位、方差、相关性都不同，欧氏距离没有概率意义。
2. 三步仿射：**中心化**去位置 → **标准化**去量纲 → **白化**去相关；四步之间是**矩阵插值动画**（2/4→3/4 先缩放视窗、再固定视窗做 Y 缩放，且不切等比例标志避免闪现），画布、公式卡、矩阵卡 `[A|b]` 同步变；注意动画是线性插值矩阵，不是简单淡入淡出。标准化/白化阶段还能看到 β 等概率椭圆与极限状态面在 x* 相切，切线就是 FORM 的线性化；Z₁ 轴 ±8、约 2 的刻度间隔。
3. 白化后等概率线变同心圆，概率密度只跟半径有关，**β 就是到原点的距离**。Cholesky 与 PCA 只差一个正交旋转：β、Pf 不变，只是验算点坐标不同。

**预期数字**：

- `L = [[2, 0], [2.5, 4.330]]`，`C = [[4, 5], [5, 25]]`，均值点 `(10, 20)`（这三项是讲师参考；页面矩阵卡显示的是当前变换的 `[A|b]`）。
- 同一个验算点：Cholesky 下 `U* = (−1.928, 0.853)`，PCA 下 `U* = (−0.381, 2.074)`（PCA 坐标讲师参考），**β 都是 2.108**；`X* = (6.144, 18.873)`（坐标在站台 4/5 的图与状态栏显示）。
- 拖 `ρ` 时 FORM 联动（结果栏同步）：`ρ = −0.8 → β 1.399 / 8.091%`；`−0.5 → 1.495 / 6.744%`；`0 → 1.717 / 4.298%`；`0.3 → 1.918 / 2.757%`；`0.5 → 2.108 / 1.750%`；`0.8 → 2.615 / 0.446%`；`0.9 → 2.976 / 0.146%`。

**常见问题**：

- **"为什么不直接用 X 空间的马氏距离？"** → 马氏距离就是白化后 U 空间的欧氏距离，β 正是它。
- **"PCA 的 U* 为什么和 Cholesky 不一样？"** → 换了一组正交基，坐标变、长度不变；`β = ‖U*‖ = 2.108` 两种写法相同。
- **"ρ 越大 β 越大？"** → 本例如此（1.399 → 2.976），原因在站台 3 讲（梯度异号 + 正相关使方差项抵消）。

> 💻 **代码抽屉**：右上"看伪代码"（transform），看 `toU / toX` 两段，约 20 秒。
> 🎯 **让学生猜**：停在 3/4（标准化后、`ρ = 0.5`）问"现在两个方向独立了吗？"——还没有，仍是斜椭圆；到 4/4 白化才独立。

### 3.3 9–16 min｜站台 3 · 均值一次二阶矩（MVFOSM）

**时间**：9–16 min（7 min）
**站台**：3 · 均值一次二阶矩——"在均值点画一条切线"
**点击路径**：按 `3`。左图是 X 空间（蓝曲线=真实边界，橙虚线=均值点切线，橙菱形=中心点法对应点，红星=FORM 验算点），右图是 U 空间（原点到切线的垂足 `U_L`）。往下看"形式敏感"卡和"误差从哪来"卡。最后开右上"看伪代码"。

**讲解要点**：

1. 只在均值点取一阶泰勒：`μ_g = g(μ) = 60`，`σ_g = √(∇gᵀC∇g) = 36.056`，`β_M = μ_g/σ_g = 1.664`，`Pf ≈ Φ(−β_M) = 4.805%`。
2. 对线性 g、正态 X 精确；本例抛物线非线性强，均值点切线离验算点远，Pf 高估 **+196.1%**——这不是数值误差，是"线性化点不对"。
3. 方法不具有不变性：同一失效面换个写法，β 就变。`R − S` 得 `3.000`；`R/S − 1` 得 `2.080`；主例题比值写法 `g₂ = X₁²/(2X₂) − 1` 得 `1.714`（而 FORM 仍是 `2.108`）。

**预期数字**：

- 画布标题旁：`β_M = 1.664，切线 X₂ = 10X₁ − 50`；另一图：`U_L = (−1.615, 0.400)，β = 1.664`；橙色菱形 `X_L = (6.769, 17.692)`（坐标讲师参考）。
- 公式卡：`μ_g = 60.000`，`σ_g = 36.056`；交叉项 `−400.0` 使 `σ_g` 从 `41.231` 降到 `36.056`。
- 误差卡（相对精确值 1.623%）：MVFOSM `+196.1%`、AFOSM/FORM `+7.9%`、SORM `+1.5%`。
- 形式敏感卡：`R − S：3.000 / 0.135%`；`R/S − 1：2.080 / 1.876%`。

**常见问题**：

- **"为什么 ρ > 0 反而让 β 变大？"** → `∂g/∂X₁ = 20 > 0`、`∂g/∂X₂ = −2 < 0` 异号；正相关让两项在方差里相消，`σ_g` 变小、β 变大。
- **"那个 −400 是哪来的？"** → `σ_g² = ∇gᵀC∇g` 展开成 `2·g₁·g₂·C₁₂ = 2·20·(−2)·5 = −400`。
- **"换个写法真的会变？太离谱了吧。"** → 站台 2 有更干净的线性小例：`R = S` 换成 `R/S − 1`，MVFOSM 从 3.000 掉到 2.080，FORM 不变。

> 💻 **代码抽屉**：mvfosm（讲完形式敏感后开，5 行：`g(μ)`、`∇g(μ)`、`σ_g`、`β`、`Φ`）。
> 🎯 **让学生猜**：先遮右栏，问"均值点法的 β 会比真值大还是小？"——本例 `1.664 < 2.108`，偏小，所以 Pf 偏大。

### 3.4 16–21 min｜站台 4 · 改进的一次二阶矩（AFOSM / 验算点法）

**时间**：16–21 min（5 min）
**站台**：4 · 改进的一次二阶矩——"沿当前 α 方向，直接找到边界"
**点击路径**：按 `4`。首次进入会自动播放一遍（想从第 0 步手动开始，先暂停/回到起点）；也可以点"播放"（或 `Space`），走完 6 步；点**迭代表任意一行**回放该步；看右侧 "AFOSM vs FORM" 卡（带 `≡ 同一设计点` 徽章）。播放条有 `◀ / 播放 / ▶ / 回到起点`。

**讲解要点**：

1. 每一步：用当前梯度算方向余弦 `α`，定一条从均值出发的射线 `x = μ + β·Lα`，沿射线解 `g = 0` 得 β，再用新点更新 α，直到 β 与 g 都不再变。
2. **第一跳会"过冲"**：`β = 2.145 > 2.108`，随后摆回。所以不能拿"第一步"当答案——这也是"为什么需要迭代"的直观解释。
3. 和 FORM 是**同一设计点、同一 β/Pf**，只是路径不同：AFOSM 在 X 空间做方向搜索，FORM 在 U 空间做切线-垂足。正态变量下两者等价。

**预期数字**：

- 6 步收敛（迭代表 1–6 行）：β `2.145 → 2.109 → 2.108 → 2.108 → 2.108 → 2.108`；`g ≈ 0`（显示为 e−14 量级）。
- 终值 `x* = (6.144, 18.873)`，`β = 2.108`，`Pf = 1.750%`。
- 对比卡：AFOSM 与 FORM 都是 `β 2.108 / Pf 1.750% / 迭代 6`。
- 第 1 跳标签："第 1 跳 β=2.145"。

**常见问题**：

- **"为什么第一跳过冲？"** → 起始梯度取自均值点，射线方向还没对准验算点；`α` 与设计点互相依赖，只能迭代。
- **"既然等于 FORM，为什么还单独讲？"** → 两种几何直觉 + 教材常用 AFOSM；同时说明"设计点"不依赖参数化方式（代数写法 / 坐标系）。

> 💻 **代码抽屉**：afosm（第一跳过冲讲完后开，看 `α → d → 解 g=0 → 回代`）。
> 🎯 **让学生猜**：只播放到第 1 步，问"下一步 β 会更大还是更小？"（本例先回落，再收敛）。

### 3.5 21–29 min｜站台 5 · FORM / HLRF（核心段）

**时间**：21–29 min（8 min）
**站台**：5 · FORM / HLRF——"切线 → 垂足 → 再切线"
**点击路径**：按 `5`。首次进入会自动播放一遍（想手动控制先暂停）；也可以先点"回到起点"，再点"播放"或按 `S` 单步 6 次；点**迭代表任意一行**回放；看右栏 **"α² 贡献"**；看下方 β_k 与 |g| 残差两张小图；收敛后开右上"看伪代码"。

**讲解要点**：

1. 每一步就是：**当前点取切线 → 原点到切线取垂足**。垂足序列就是迭代表；收敛后 β 就是"原点到极限状态面的最近距离"。
2. **第 1 步的垂足正好是均值点法的 `U_L`（β = 1.664）**——所以 MVFOSM 可以看作 HLRF 的第 1 步。这是把两种方法串起来的关键一句。
3. 收敛后 `β = ‖U*‖ = 2.108`；`α = (−0.915, 0.405)`，`α² = (83.6%, 16.4%)` 是各变量对 β 的方差贡献；`Pf ≈ Φ(−β) = 1.750%`。

**预期数字**：

- 迭代表 k = 0…6（7 行）：β `0 → 1.664 → 2.090 → 2.108 → 2.108 → 2.108 → 2.108`；`g` 残差 `60 → 10.44 → 0.44 → … → 7.6×10⁻⁹`（|g| 小图是 log 轴，直线下坠）。
- `U* = (−1.928, 0.853)`，`X* = (6.144, 18.873)`；结果栏 β 显示 `2.108`，公式卡显示 `2.1083`。
- 状态栏："共 6 次迭代"；结果卡备注"U 空间 HLRF；6 次迭代收敛。"
- 改 `ρ` 可现场验证"ρ 大时会多几步"：`ρ = 0.8 → β 2.615 / 0.446% / 8 次`；`ρ = 0.9 → β 2.976 / 0.146% / 11 次`。

**常见问题**：

- **"Pf = Φ(−β) 什么时候不能用？"** → 只在半空间/线性边界严格；非线性时是 FORM 近似（帮助对话框"符号约定"和第 6 站都在强调这一点）。
- **"α 的符号为什么和教材相反？"** → 本页 α 指向验算点：`α = −∇g(u*)/‖∇g(u*)‖`，`u* = βα`；教材常把 α 取梯度方向，写成 `x* = μ − βασ`，符号相反、本质相同。
- **"X₁ 占 83.6% 说明什么？"** → β 主要由 X₁ 控制；想提高可靠度，先动 X₁（拖小 `σ₁` 或增大 `μ₁` 看 β 上升）。
- **"残差图为什么是 log 轴？"** → 正常迭代是近似平方收敛，残差掉得比线性快，log 轴上看着像陡直线。

> 💻 **代码抽屉**：form（HLRF 迭代 7 行，与迭代表一一对应）。
> 🎯 **让学生猜**：播放前问"第 0 步 β=0，垂足会落在哪？"；收敛后再问"再多迭代 β 会变吗？"（不变，已收敛）。

### 3.6 29–34 min｜站台 6 · SORM / Breitung

**时间**：29–34 min（5 min）
**站台**：6 · SORM——"β 不变，Pf 因曲率修正"
**点击路径**：按 `6`。勾 **"曲率示意放大 ×3"**（只影响绘图，不影响计算）；再勾 **"显示密切圆"**；看右侧 4 个指标卡和 "Pf 对比"条。

**讲解要点**：

1. FORM 把边界当直线；SORM 在**同一个验算点**加二阶曲率 `κ`，把边界当抛物线，只修正 Pf 的换算（n = 2：`Pf ≈ Φ(−β)/√(1 + βκ)`）。
2. **β 不变、验算点不重新找**：`κ = 0.0612`，`βκ = 0.129`，修正因子 `0.941`；Pf 从 `1.750%` 降到 `1.647%`，相对精确值的误差从 `+7.9%` 降到 `+1.5%`。
3. 修正方向的符号约定：本页 `κ > 0` 表示边界朝失效域弯、失效域变小，所以 Pf 变小；教材若取相反法向，公式会写成 `(1 − βκ)`。放大的 ×3 只改画面。

**预期数字**：

- 画布角标：`κ = 0.0612 · βκ = 0.129 · 因子 0.941`。
- 指标卡：主曲率 `κ = 0.0612`，`1/κ ≈ 16.35`；`βκ = 0.129`；修正因子 `0.941`；`Pf (SORM) = 1.647%`（FORM `1.750%`）。
- 对比条：FORM `1.750% (+7.9%)`、SORM `1.647% (+1.5%)`、精确 `1.623%`。

**常见问题**：

- **"为什么只改 Pf、不改 β？"** → β 由一阶条件定义（最近距离）；SORM 是在同一点补二阶信息。"β = 距离"与"Pf = Φ(−β)"是两件事。
- **"κ 这么小，修正怎么有 5.9%？"** → 因子 `1/√(1.129) = 0.941`，直接乘掉约 5.9% 的 Pf；而 Pf 对 β 本来就极敏感。
- **"放大 ×3 会不会把数字也放大？"** → 不会，画图专用，页面已标注"放大只影响画图，不影响计算"。

> 💻 **代码抽屉**：sorm（Hessian → 法向/切向 → κ → 因子，4 行核心）。
> 🎯 **让学生猜**：先问"加了曲率，Pf 会变大还是变小？"再勾放大验证。

### 3.7 34–39 min｜站台 7 · 蒙特卡洛

**时间**：34–39 min（5 min）
**站台**：7 · 蒙特卡洛——"用大样本做基准"
**点击路径**：按 `7`。首次进入会自动连续抽样到 10 万（想手动控制先点 `暂停`/`重置`；想打开时空白用 `?auto=0`）。也可以先把 **目标 N** 设成 `100000`，点 **“重抽到 N”**（一步到位；也可点“连续抽样”看样本云逐批出现，“每批”可调到 100–20000）；切 **X / U 空间**看同一批样本；看“运行估计与 95% CI”图和指标卡。

**讲解要点**：

1. 不线性化：直接按 `N(μ, C)` 抽样、数 `g < 0` 的比例。所以它检验的是前面所有近似，而不是"更高级的答案"。
2. 误差 ∝ `1/√N`：10k 时 COV ≈ 7.9%、100k ≈ 2.5%；**95% CI 是抽样误差，不是模型误差**。
3. 固定种子 `20261119` 可复现；页面抽样上限 **10 万**，`4×10⁶` 只是默认参数下的预置参考（65,121 个失效）。

**预期数字**（种子固定、默认参数，从零“重抽到 N”=100000，结果可复现）：

- 100k：失效 `1,585` → `Pf = 1.585%`，COV `2.5%`，95% CI `±0.077%`（绝对百分点）。
- 10k：失效 `158` → `Pf = 1.580%`，COV `7.9%`，95% CI `±0.244%`。
- 1k：失效 `20` → `Pf = 2.000%`，COV `22.1%`——样本太少，只能看趋势。
- 预置参考：N = 4×10⁶，`Pf = 1.628%`（站台 0 卡片显示 `1.63%`；站台 8 对比表显示 `1.628%`，并注明"参考 N=4×10⁶"；`se` 等中间量在 Python 基准里）；精确 `1.623%`，FORM `1.750%`。
- 结果栏：MC / 模拟 / note "N=100,000；95% CI ±0.077%"。

**常见问题**：

- **"为什么每个同学抽出来不一样？"** → 若都从零开始、目标 N=100000 点“重抽到 N”，种子固定结果一样；中途改参数、重置顺序不同就会变。CI 就是描述这种波动。
- **"要不要抽 400 万？"** → 页面封顶 10 万（课堂时间考虑）；4×10⁶ 参考值已在基准表里，用来说明"要 0.4% 的 COV 需要多大样本"。
- **"MC 和 FORM 谁对？"** → MC 是基准但不是真值；它与精确 1.623% 在 CI 内一致，说明 FORM 的 +7.9% 是线性化误差。

> 💻 **代码抽屉**：mc（伪代码 8 行 + 二项标准误）。

### 3.8 39–43 min｜站台 2 · 概率干涉

**时间**：39–43 min（4 min）
**站台**：2 · 概率干涉——"R 与 S 重叠多少，才算失效？"
**点击路径**：按 `2`。注意：**进入本站在右栏"主例题参数 / 方法对比"会隐藏**，`R`、`S` 的 4 个滑块在主区右侧（R 均值 20–40、S 均值 5–25、R/S 标准差 1–8）。看三张图：① 密度重叠，h(s) 与 f_R/f_S 同一绝对密度轴 ② h(s)=f_S·F_R（面积 = Pf）③ 安全裕度 `g = R − S`；看"形式敏感"小表。现场把 S 均值从 15 拖到 18。

**讲解要点**：

1. **重叠面积只是"看起来危险"，不是 Pf**（图上直接标注）；真正的 Pf 是 `h(s)=f_S(s)F_R(s)` 的积分——图②曲线下的面积；图①的 h(s) 与 f_R/f_S 共用绝对密度轴，所以它看起来很小，这正说明失效密度只占重叠区的一小部分。
2. R、S 独立正态时 `g = R − S` 也是正态：`β = (μ_R − μ_S)/√(σ_R² + σ_S²)`，`Pf = Φ(−β)` **精确**（本例 β = 3.000）。
3. 同一失效面 `R = S` 换个写法：`R − S` 与 `R/S − 1` 的 MVFOSM β 不同（`3.000` vs `2.080`），FORM 都是 `3.000`——形式敏感在"线性 g"上最干净。

**预期数字**：

- 默认 `β = 3.000`，`Pf = 0.135%`，可靠度 `99.865%`；`μ_g = 15`，`σ_g = 5`（`√(4² + 3²)`，这两项讲师参考）。
- 形式敏感表：`R − S`：MVFOSM `3.000` / FORM `3.000`；`R/S − 1`：MVFOSM `2.080` / FORM `3.000`。
- 现场改参数：S 均值 15 → 18，`β = 2.400`、`Pf = 0.820%`（Pf 约涨 6 倍）。

**常见问题**：

- **"为什么 FORM 对 R/S − 1 也精确？"** → 该例两种写法的零集都是直线 `R = S`；FORM 在验算点线性化后恰好就是这条直线，没有线性化误差。对一般非线性 g，FORM 仍是一阶近似。
- **"重叠这么多，Pf 怎么才 0.135%？"** → 两条分布确实有重叠，但要同时落在 `R < S` 的尾部，概率很小。
- **"怎么没有主例题的滑块了？"** → 本站用 R/S 自己的四个滑块（主区右侧），主例题参数卡暂时隐藏，避免两套参数混用。

> 🎯 **让学生猜**：先问"这两条曲线重叠这么多，Pf 有 10% 吗？"——实际 0.135%。

### 3.10 可选加餐 2–3 min｜站台 9 · 同图与切线误差

**时间**：可选（主路线不含；前面压出 2–3 min 或单独一节课时讲）
**站台**：9 · 同图与切线误差
**点击路径**：按 `9`。左图看 MVFOSM 切线（橙）、AFOSM=FORM 切线（红）、SORM 二阶（绿）叠在同一张图；右上 `X/Y/Z/U` 切空间，等概率椭圆（U 空间为圆）会一起画；下方色条同时给 β/Pf。右图默认 β=2.108、κ=0.5，点四个失效域按钮切换阴影，选中的曲线高亮、其余淡化。

**讲解要点**：

1. **同图**：MVFOSM 的 `g=0` 线性化边界在均值点上方（均值处 g=60，不在 g=0 上），AFOSM=FORM 的切线在设计点，SORM 是设计点附近的二阶曲线；浅橙虚线是过 μ 的平行切线，用来解释 MVFOSM 的偏移。
2. **空间**：X/Y/Z/U 四张图是同一组几何对象的仿射变换；U 空间里等概率椭圆变圆，β 是到原点的距离。
3. **切线误差**：同一 β、不同边界形状，`Φ(−β)` 的误差不同。默认：线性 1.752%、凸 1.154%（−34.1%）、凹 4.193%（+139.4%）、圆外 10.841%（+518.9%，等效 β 1.235）。
4. **极端案例**：失效域在密度等高线外（圆外 r>β）时，Pf=exp(−β²/2)，直线切线把 Pf 低估约 6 倍；所以 `Pf=Φ(−β)` 只对半空间严格。
5. 拖 `β`、`κ` 滑块，让学生看误差如何随曲率和 β 变化；κ=0 时凸/凹/线性重合。

> ⏭ 如果只能加 1 分钟：只讲右表最后一行“圆外 10.841% vs 线性 1.752%”。

### 附录 E · 学生高频问题标准回答

1. **为什么 β 要在 U 空间定义？** 因为 X 空间各分量单位/方差/相关都不同，距离没有概率意义；白化后概率密度只跟半径有关，"最近"才等于"最可能"。
2. **MVFOSM 为什么换个写法就变？** 它只在均值点做一阶泰勒，线性化误差依赖 `g` 的代数形式；`R−S` 与 `R/S−1` 零集相同但均值点梯度不同，`3.000` vs `2.080`。
3. **为什么 AFOSM 与 FORM 数值相同？** 正态变量下两者都收敛到"U 空间到零集的最近点"，同一设计点、同一 β，只是搜索路径不同。
4. **SORM 为什么改 Pf 不改 β？** β 由一阶（最近点）条件定义；SORM 在同一点补二阶曲率，只改 Pf 的换算。
5. **MC 每次不一样，可信吗？** 固定种子可复现；95% CI 描述抽样误差。Pf 小的时候相对误差 ∝ `1/√(N·Pf)`。
6. **α 的符号和教材相反？** 本页 α 指向验算点，`u* = βα`；教材常取梯度方向写成 `x* = μ − βασ`，符号相反、本质相同。
7. **ρ 大为什么 β 大？** 本例梯度分量异号，正相关使方差交叉项为负、`σ_g` 变小，β 变大。
8. **什么时候必须用 MC？** 维数高、非线性强、非正态、没有解析梯度或需要基准校核时；本例用 MC 检验 FORM/SORM。
9. **β 相同 Pf 一定相同吗？** 不一定。`Pf = Φ(−β)` 只在半空间/线性边界严格；同样是 β = 2.108，如果边界是圆（χ² 型），`Pf = exp(−β²/2) ≈ 10.83%`。页面没有画这个反例，可口述或板书作课后思考。
10. **页面数字怎么信？** 全部现场计算；帮助对话框有 **20 项数值自检**（当前 20/20 通过），另有 `reference_values.py` 独立 Python 基准。

### 附录 G · 数值口径与自检

- 页面所有数字由 `src/js/model.js` 现场计算；默认参数为 `μ₁=10, μ₂=20, σ₁=2, σ₂=5, ρ=0.5`，变换用 Cholesky。
- HLRF 收敛判据 `|g| < 1e-8`、最多 30 步；SORM 用解析 Hessian（Python 基准另有有限差分交叉校核）。
- MC 固定种子 `20261119`（页脚显示 `seed 20261119`）；页面抽样上限 10 万；`4×10⁶` 的参考值来自 Python 基准。
- 自检：帮助对话框 →"运行数值自检"（或 `?selftest=1`），逐项显示 PASS/FAIL；若页面脚本本身报错，页顶会出现红色错误条。
- 独立复算：`python reference_values.py`（numpy），输出 MVFOSM / HLRF 迭代表 / SORM / 精确 / MC / ρ 扫描 / R−S 小例，与页面显示一致到显示位数。
- 本文写的是**屏幕显示值**：β 3 位小数、Pf 3 位小数；公式卡里 β 可显示到 4 位（如 `2.1083`），不是矛盾。
