## 1. 怎么打开

| 步骤 | 做法 |
|---|---|
| 1 | 双击根目录的 `structural-reliability-lab.html`；`dist/` 下有同名副本，内容相同 |
| 2 | 用 **Chrome 或 Edge** 打开（Chromium 内核）；投影建议 1920×1080，至少 1280×800 |
| 3 | 不需要联网、不需要安装：单文件、无外部请求、无 CDN；公式是内嵌 SVG，不依赖字体服务器 |

使用前说明：

- 页面是**构建产物**。改过 `src/` 之后要运行 `python tools/build.py` 重新生成根目录和 `dist/` 两份；`src/index.html` 直接打开也能跑（它引用同目录的 CSS/JS），但课堂分发、拷贝、打印请以根目录单文件版为准。
- `file://` 下浏览器可能禁止页面回写地址栏（代码已静默忽略），不影响站台切换和演示。
- 窗口宽度 **小于 1024 px** 时，右侧结果栏会自动隐藏；**小于 760 px（或手机横屏）**时自动进入手机布局（见 4.6 节）。
- 若页面顶部出现红底“页面脚本错误”横幅，按 F5 刷新；仍出现就先在命令行运行 `node tests/test_math.js` 确认数值内核正常。

### 3.1 各站台的操作要点

**站台 0 · 总览**

- 点任意结果卡片直接跳到对应站台（MVFOSM→3、AFOSM→4、FORM→5、SORM→6、MC→7、精确→8）。
- 默认参数下看 4.80% 与 1.62% 的差距；MC 参考值是 N=4×10⁶，只在默认参数下显示。

**站台 1 · 变量与变换**

- 用卡片内的 `←` `→`、4 个步骤按钮，或右上 `播放` 在 1/4 → 4/4 之间切换；切换时画布用 **1.05 s（白化步 1.25 s，标准化步 1.4 s）**做仿射矩阵插值动画（等概率椭圆、极限状态面、设计点一起连续变形）。**2/4 → 3/4 特意分两段**：先把坐标视窗缩放到标准化的比例，再固定视窗、对数据做 Y 轴缩放；全程不切换 `equal` 标志，避免整图闪现。Z₁ 轴用对称 ±8、约 2 的刻度间隔，负/正两侧都有刻度；曲线和失效域按窗口外延绘制再裁剪，所以每个视窗里曲线是连续的、充满窗口的，不会在数据端点停住。二步起还画出 **β 等概率椭圆/圆** 和它在切点 x* 的 **FORM 切线**。X/Y 零轴线和刻度也做了加粗。也可用 `?transplay=1` 自动播放。右侧“变换方式”卡片里可在 `Cholesky / PCA` 之间切换白化写法。
- 两种白化只差一个正交旋转：β、Pf 不变，U 空间验算点坐标不同（可对照公式卡）。
- 虚线圈是 r=1、2、3 的等概率椭圆/等 β 圆；红星是设计点。

**站台 2 · 概率干涉**

- 右侧四个滑块（R 均值、S 均值、R 标准差、S 标准差）只影响本站台，主例题参数卡在本站台隐藏。
- 三张图：① 密度重叠，h(s)=f_S·F_R 与 f_R/f_S 共用**同一绝对密度轴**（h(s) 数值很小，但保持真实比例；放大看用图②）② 失效概率密度 h(s)（面积=Pf）③ 安全裕度 g=R−S；橙色重叠面积不是 Pf。
- 下方“形式敏感”表：R−S 与 R/S−1 零集相同，MVFOSM 的 β 都是 3.000 / 2.080，FORM 都是 3.000。

**站台 3 · 均值一次二阶矩**

- 左图 X 空间：均值点切线（默认参数下 X₂ = 10X₁ − 50）；右图 U 空间：原点到切线的垂足 U_L。
- “形式敏感”卡片说明同一失效面换写法后 β 会变；“误差从哪来”给出相对精确值的 Pf 误差（MVFOSM +196.1%）。

**站台 4 · 改进的一次二阶矩（AFOSM）**

- `◀` `▶` 单步、`播放` 连续播放、`回到起点` 归零；迭代表点任意一行可回放该步。
- **首次进入本站会自动播放一次**（页面打开时就在本站也会；约 0.7 秒一步，播到收敛后停）。想手动控制就点 `播放`/`‖` 暂停。
- 默认参数下 6 步收敛：第 1 跳 β≈2.145，随后在 2.108 附近收敛；右侧有 AFOSM vs FORM 对照。

**站台 5 · FORM / HLRF**

- `◀` `▶` / `播放` 逐迭代播放（约 0.7 秒一步）；**首次进入本站会自动播放一次**。默认参数下迭代表 7 行：k=0 是均值点，k=1…6 是 6 次迭代（ρ 大时会更多）。
- 迭代表点行回放；α² 条形图显示 X₁ 约 83.6%、X₂ 约 16.4% 的方差贡献。
- 下方两张小图：β_k 收敛曲线、|g(U_k)| 残差（log 轴）。

**站台 6 · SORM**

- 指标卡：主曲率 κ≈0.0612、βκ≈0.129、修正因子 0.941、Pf（SORM）。
- 两个复选框：`曲率示意放大 ×3` 只放大画图、不影响计算；`显示密切圆` 只增加示意。
- 下方 Pf 对比条同时给 FORM、SORM、精确值的相对误差（FORM +7.9%、SORM +1.5%）。

**站台 7 · 蒙特卡洛**

- 抽样控制：`重置`（清零）、`每批 [1000] 个`（可改 100–20000）、`抽一批`（按每批数量加）、`目标 N [100000]`（可改 1000–100000）、`重抽到 N`（先清零再抽到目标，种子固定可复现）、`连续抽样`（约 95 ms 按“每批”数量增加）。
- **首次进入本站会自动开始连续抽样**，抽到 10 万自动停；点 `暂停` 可停，`重置` 清零。想打开时保持空白，可在 URL 加 `&auto=0`。
- 样本云可在 `X` / `U` 空间之间切换；红色是失效样本 g<0。
- 指标卡显示 N、失效数、Pf、COV、95% CI；下方曲线是运行估计与 95% CI 带，并画出精确值与 FORM 参考线。
- 随机种子固定为 `20261119`，只用于**蒙特卡洛抽样**（站台 7 和站台 10 的 MC）：同样的操作顺序可复现同样的样本序列。FORM/SORM/MVFOSM/精确积分/干涉/变换等确定性计算不使用随机数，不受种子影响。

**站台 8 · 公式与代码**

- 7 组公式：基础与换算、空间变换、均值一次二阶矩、改进的一次二阶矩、FORM/HLRF、SORM/Breitung、模拟与干涉。
- 还有：当前参数下的方法对比表（含 Pf 相对误差）、β↔Pf 换算表、7 个算法伪代码按钮（与各方法站台右上角按钮是同一份内容）。
- 站台 8 右上角的“打印公式卡”仍在这里打印，详见第 7 节。

**站台 9 · 同图与切线误差**

- 左图把 MVFOSM 切线（橙）、AFOSM=FORM 切线（红）、SORM 二阶曲线（绿）和极限状态面叠在同一张图；右上 `X / Y / Z / U` 切换空间，等概率椭圆（U 空间为圆）随空间一起画；下方色条同时给出各方法 β/Pf。极限状态面/失效域画到窗口外再裁剪，U 空间图不会在数据端点被截断。
- 左图现在是**固定 1:1 视图**：X 空间用 `0–22` 的方窗（两轴单位长度一致），U 空间以设计点 β 为中心做方窗；画布为正方形，原点连线可以直接目测。去掉了“自适应 / 1:1”开关，进入站台 9 直接就是同比例视图。
- 图支持**自由缩放/平移**：滚轮缩放（以鼠标位置为中心）、按住拖动平移、双击复位；右上 `−` / `＋` / `⟲` 也可缩小/放大/复位。切换空间时视图会自动回到该空间的基准范围。
- 各方法点旁标出 **β = 到原点（圆心）的距离**：MVFOSM 的 U_L 标 `β_M=1.664`，AFOSM/FORM 设计点标 `β=2.108`，SORM 同设计点标 `β=2.108`。固定 1:1 后视觉距离与统一比例一致。
- MVFOSM 的 `g=0` 线性化边界**不穿过均值**（均值处 g=60），浅橙虚线是过 μ 的平行切线，二者相差 `g/‖∇g‖`；图上分别标注，避免把“均值点”误认为在边界上。
- 右图是切线误差案例：同一设计点 β，比较线性 / 凸 / 凹 / 圆外四种失效域；可拖 `β`、`κ` 滑块，点四个失效域按钮切换阴影，**选中的曲线高亮、其余淡化**，表格同步高亮当前行。边界和失效域填充都画到窗口外再裁剪，窗口内不会在 `U₂≈±4.5` 处出现断头。
- 默认 β=2.108、κ=0.5：线性 1.752%、凸 1.154%（−34.1%）、凹 4.193%（+139.4%）、圆外（极端）10.841%（+518.9%，等效 β 1.235）。圆外案例就是“失效域在密度等高线外”，说明 `Pf=Φ(−β)` 只在半空间严格。

**站台 10 · 自定义函数实验室**

- 在 **`g =`** 输入框输入两变量函数，例如 `x1^2 - 2*x2`、`x1 + x2 - 30`、`20 - sqrt(x1^2 + x2^2)`；支持 `+ − * / ^`、括号、`sin/cos/exp/log/sqrt/abs/min/max` 等。回车或点 **`计算`** 生效；下方“抛物线/线性/圆外/乘积/正弦/多失效区”是快捷示例。`正弦` 使用 `sin(x1) + x2 - 19`（只有一块失效区，便于讲单设计点）；`多失效区` 使用 `sin(x1) + 2cos(x2) + 1`，有多个互不连通的失效域，用于演示单设计点 FORM/SORM 的局限。页面会统计失效区连通块并提示“多失效区，FORM/SORM 只取一个设计点，请以 MC 为参考”；如果函数在视窗内恒正或恒负，则明确提示“没有 g=0”。
- **数据位置**：μ₁、μ₂、σ₁、σ₂、ρ 五个滑块直接改正态分布；改完自动重算。`σ` 必须大于 0。
- **方法选择**：MVFOSM / FORM(AFOSM) / SORM / MC 可勾选；FORM 与 AFOSM 在正态空间是同一设计点；MC 每次 10 万样本，给 95% CI。
- 左侧画布现场绘制 **g=0 曲线、失效域、β 等概率椭圆、MVFOSM 切线与 FORM 切线、均值点/设计点/MVFOSM 垂足**；右侧结果表给 β、Pf 和备注。
- 任意函数没有“精确解析值”；FORM/SORM 是近似，MC 是参考。函数不连续、奇异或非光滑时，请把结果当作方法演示，不要当成保证。
- URL 可用 `?station=10&fn=x1%5E2%20-...` 直接打开某个函数；`C` 键可跳到本站。

### 4.4 方法对比表

固定 6 行：MVFOSM、AFOSM、FORM、SORM、MC、精确。

- 默认参数下 MC 行显示“参考 N=4×10⁶”的 1.628%（离线基准值，不是现场抽样）。
- 改过参数后 MC 行显示“站台 7”或本次抽样的 N 与 Pf；β 列对 MC、精确显示“—”。
- 表下注释强调：AFOSM 与 FORM 在正态变量下是同一设计点（≡）；SORM 的 β 不变，只修正 Pf。

## 8. 数值自检

页面内所有数字都是 JS 当场计算的。核对方式有三种：

| 方式 | 操作 | 看到什么 |
|---|---|---|
| 页面入口 | 按 `?` 打开帮助 → `运行数值自检` | 逐项 PASS/FAIL，末行“20 / 20 通过” |
| URL 参数 | 打开页面时加 `?selftest=1` | 自动弹出帮助对话框并运行自检 |
| 命令行 | `node tests/test_math.js` | 打印主要数值和 `20/20 passed` |

- 自检共 **20 项**，覆盖 Φ、Cholesky、MVFOSM、HLRF 的 β/u*/x*、PCA 下 β 不变、SORM 的 κ 与 Pf、精确值、R−S、R/S−1 和主例题的比值写法。

- `?selftest=1` 运行后，在 Chrome/Edge 下地址栏里的 `selftest` 会被移除，刷新不会自动再跑；若浏览器禁止改写地址栏，刷新可能再次自检。

## 9. URL 参数：复现某一幕

在页面地址后面加查询参数。页面**加载时读取一次**，之后滑块仍可继续改。

| 参数 | 含义 | 取值与规则 |
|---|---|---|
| `station` | 站台 | 0–10；越界自动夹到范围内；默认 0 |
| `trans` | 站台 1 的变换步骤 | 0–3，对应 1/4–4/4；越界夹取 |
| `transplay` | 加载后自动播放站台 1 的 4 步变换 | 只认 `1`（`?station=1&transplay=1`） |
| `hlr` | 站台 5 停在 HLRF 第几步 | 默认参数下 0–6；越界夹到当前历史长度内 |
| `af` | 站台 4 停在 AFOSM 第几步 | 默认参数下 0–5；越界夹取 |
| `mc` | 加载后先抽多少 MC 样本 | 正整数；页面最多抽到 **100000**，超过按 10 万处理 |
| `mode` | 白化写法 | `chol` 或 `pca`；其他值忽略 |
| `projector` | 投影模式 | `1` 打开、`0` 关闭；顶栏按钮已移除，请用 URL |
| `auto` | 首次进入站台 4/5/7 是否自动演示 | `0` 关闭；默认开启（显式带 `af`/`hlr` 时自动关闭，避免覆盖分享的步数） |
| `allspace` | 站台 9 同图空间 | `x` / `y` / `z` / `u`；同时会跳到站台 9 |
| `fn` | 站台 10 的初始函数表达式 | URL 编码后的字符串，如 `?station=10&fn=x1%5E2-2*x2` |
| `code` | 加载后打开代码抽屉 | `overview`、`transform`、`interference`、`mvfosm`、`afosm`、`form`、`sorm`、`mc` |
| `selftest` | 加载后跑数值自检 | 只认 `1`（`?selftest=1`） |
| `mu1` `mu2` `s1` `s2` `rho` | 主例题参数 | 超出滑块范围会夹取；默认 10 / 20 / 2 / 5 / 0.5 |
| `muR` `muS` `sR` `sS` | 站台 2 的 R/S 参数 | 范围 20–40 / 5–25 / 1–8 / 1–8；默认 30 / 15 / 4 / 3 |

常用示例（把文件名换成实际路径即可）：

| 想复现 | URL |
|---|---|
| 停在 HLRF 第 3 步 | `structural-reliability-lab.html?station=5&hlr=3` |
| AFOSM 回到起点 | `structural-reliability-lab.html?station=4&af=0` |
| 变换最后一步 + PCA 写法 | `structural-reliability-lab.html?station=1&trans=3&mode=pca` |
| 打开投影模式 | `structural-reliability-lab.html?projector=1` |
| 加载即抽 5 万样本 | `structural-reliability-lab.html?station=7&mc=50000` |

| 打开 SORM 代码抽屉 | `structural-reliability-lab.html?station=8&code=sorm` |

## 11. 已知边界（页面上没有的功能）

- 主例题只支持 **2 个随机变量、正态分布**（X₁、X₂ 相关或独立）；站台 2 的 R/S 也只支持独立正态。
- 只有两个内置例题：抛物线 `g=X₁²−2X₂` 和 R−S 干涉；**不能输入任意 g(x)**，也不支持非正态变量、当量正态化、子集模拟。
- 重要性抽样（IS）只在 `reference_values.py` 里作为数值对照出现，**页面上没有 IS 功能**。
- 页面 MC 上限 **10 万**样本（性能考虑）；4×10⁶ 的 1.628% 是离线基准，“方法对比”表在默认参数下引用它，但不能在页面上现场抽 4M。
- 页面 MC 种子固定为 `20261119`；每次重置/刷新后抽样序列相同，换种子需要改源码。
- AFOSM 与 FORM 在正态变量下是**同一设计点**，β/Pf 相同，不要当成两个独立方法；SORM 沿用 FORM 的设计点，只修正 Pf。
- 页面显示的 β 为 3 位小数；Pf 通常也是 3 位小数（“方法对比”表默认按 2 位显示，小于 1% 时仍按 3 位）；页面用 A&S 近似计算 Φ，与 Python 基准的差别在 10⁻⁷ 量级，**3 位显示一致**。
- 窗口小于 1024 px 时右侧结果栏隐藏；`F` 全屏可能被浏览器策略拒绝。
