## 1. 主例题定义

| 项目 | 内容 |
|---|---|
| 极限状态函数 | g(X) = X₁² − 2X₂ |
| 失效域 | g < 0，即 **X₂ > X₁² / 2** |
| 随机变量 | X₁ ~ N(10, 2²)，X₂ ~ N(20, 5²)，相关系数 ρ₁₂ = 0.5 |
| 均值向量 | μ = (10, 20) |
| 标准差向量 | σ = (2, 5) |
| 协方差矩阵 | C = [[4, 5], [5, 25]]（非对角元 = ρσ₁σ₂ = 0.5×2×5 = 5） |
| Cholesky 分解 | L = [[2, 0], [2.5, √18.75]]，√18.75 = 4.3301270189 |
| 变量变换 | X = μ + L U，U ~ N(0, I)；即 U = L⁻¹(X − μ) |
| 梯度 | ∇g(X) = (2X₁, −2)；在均值点 ∇g(μ) = (20, −2) |
| Hessian | H = [[2, 0], [0, 0]]（线性于 X₂、二次于 X₁） |
| 均值点函数值 | g(μ) = 10² − 2×20 = **60** |

失效面是抛物线 X₂ = X₁²/2；X₁ 越大越危险，X₂ 的方差（σ₂ = 5）远大于 X₁（σ₁ = 2），且两者正相关。

## 3. MVFOSM（均值点一次二阶矩）

| 量 | 值 |
|---|---|
| μ_g = g(μ) | 60 |
| σ_g² = ∇g(μ)ᵀ C ∇g(μ) | 20²×2² + (−2)²×5² + 2×20×(−2)×5 = 1600 + 100 − 400 = **1300** |
| σ_g | **36.055513**（√1300） |
| β_M = μ_g / σ_g | **1.6641005887** |
| Pf ≈ Φ(−β_M) | **4.80462%**（0.0480461647） |
| 交叉项 2∂₁g∂₂g·C₁₂ | **−400**（若忽略交叉项，σ_g 会是 √1700 = 41.231，β 会被算小） |
| 均值点切线 | X₂ = 10X₁ − 50（由 g(μ) + ∇g(μ)ᵀ(X − μ) = 0 得到） |
| U 空间垂足 U_L | (−1.615385, 0.399704) |
| 对应 X 空间点 x_L | (6.769231, 17.692308) |

要点：MVFOSM 的 U_L 正好等于 HLRF 迭代的 **k = 1** 那一步（见第 4 节），所以教材常说“MVFOSM 是 HLRF 的第 1 步”。

## 4. FORM / HLRF

### 4.1 迭代过程（7 个点）

默认参数、容差 |g| < 10⁻⁸、最多 30 次迭代。k = 0 是均值点，之后 **6 次迭代**收敛：

| k | u₁ | u₂ | β_k = ‖u_k‖ | g(u_k) |
|---|---|---|---|---|
| 0 | 0.000000 | 0.000000 | 0.000000 | 6.000000×10¹ |
| 1 | −1.615385 | 0.399704 | 1.664101 | 1.044×10¹ |
| 2 | −1.945586 | 0.763207 | 2.089926 | 4.361×10⁻¹ |
| 3 | −1.925743 | 0.858099 | 2.108275 | 1.575×10⁻³ |
| 4 | −1.928381 | 0.852313 | 2.108339 | 2.783×10⁻⁵ |
| 5 | −1.928042 | 0.853082 | 2.108340 | 4.592×10⁻⁷ |
| 6 | −1.928086 | 0.852983 | 2.108340 | 7.647×10⁻⁹ |

页面迭代表显示到 3 位小数（u、β）；g 列在 |g| < 10⁻² 时用科学计数法，否则按两位小数。按这个规则，k = 0、1、2 的 g 显示为 60.00、10.44、0.44；k = 3 的 g = 1.575×10⁻³ 显示为 **1.6e-3**；k = 4、5、6 分别显示 2.8e-5、4.6e-7、7.6e-9。

### 4.2 设计点与方向余弦

| 量 | 值 |
|---|---|
| u* | (−1.928086, 0.852983) |
| x* = μ + L u* | (6.143828, 18.873311) |
| g(x*) | 7.647×10⁻⁹（≈0） |
| β = ‖u*‖ | **2.1083396823** |
| α = u*/β | (−0.914504, 0.404576) |
| α²（U 空间方差贡献） | **83.6318% / 16.3682%** |

差异量级：u*、x* 约 10⁻⁵～10⁻⁴，β 约 3×10⁻¹⁰，Pf 约 6×10⁻⁸。页面显示 3 位小数时两者完全相同；自检里 x* 的阈值（10⁻⁵）是按页面内部值设的。

### 7.2 页面现场抽样（seed = 20261119，可复现）

页面用 JS 的 mulberry32 + Box–Muller 随机数，序列与 numpy 不同，但种子固定；同样的操作顺序结果确定：

| 样本数 N | 失效数 | Pf | COV | 95% CI 半宽 |
|---|---|---|---|---|
| 10,000 | 158 | **1.580%** | 7.89% | ±0.244 个百分点 |
| 100,000 | 1,585 | **1.585%** | 2.49% | ±0.077 个百分点 |

- 页面提示的 COV 量级：10k 约 7.8%、100k 约 2.5%（与按参考 Pf 算出的理论值一致）。

## 8. 精确值（主例题的一维条件积分）

主例题可以“对 X₁ 条件化”后做一维积分：

给定 X₁ = x₁ 时，X₂ | X₁ ~ N(m(x₁), s_cond²)，其中

- m(x₁) = μ₂ + ρ·σ₂/σ₁·(x₁ − μ₁) = 20 + 1.25(x₁ − 10)
- s_cond = σ₂·√(1 − ρ²) = 5×√0.75 = **4.3301270189**

失效条件 X₂ > X₁²/2，所以

> Pf = ∫ φ((x₁ − μ₁)/σ₁)/σ₁ · Φ((m(x₁) − x₁²/2) / s_cond) dx₁

数值实现：

| 实现 | 方法 | 区间与点数 | 结果 |
|---|---|---|---|
| Python `exact_pf` | 梯形积分 | [μ₁−8σ₁, μ₁+8σ₁] = [−6, 26]，400,001 点 | **0.016226296294 = 1.62263%** |
| 页面 `exactParabola` | Simpson 积分 | [−6, 26]，1600 个区间 | 0.016226300500 = 1.62263% |

两者独立实现相差 4.2×10⁻⁹；页面显示 3 位小数为 1.623%，结果卡显示 1.623%，公式卡对比表显示 1.623%。

## 9. 形式敏感：R−S vs R/S−1

R ~ N(30, 4²)，S ~ N(15, 3²)，相互独立（站台 2 默认参数）。

### 9.1 两种写法（同一失效面 R = S）

| 写法 | g | μ_g | σ_g | MVFOSM β | MVFOSM Pf | FORM β | FORM Pf |
|---|---|---|---|---|---|---|---|
| R − S | R − S | 15 | 5 | **3.000000** | **0.134990%** | 3.000000 | 0.134990% |
| R/S − 1 | R/S − 1 | 1 | 0.480740 | **2.080126** | **1.875700%** | 3.000000 | 0.134990% |

- R−S 是线性的、且 R、S 独立正态，所以 MVFOSM、FORM 都精确：β = (30−15)/√(4²+3²) = 3，Pf = Φ(−3) = 0.1349898%。
- R/S−1 的推导：g(μ) = 30/15 − 1 = 1；∂g/∂R = 1/15，∂g/∂S = −30/15² = −2/15；
  σ_g² = (1/15)²×4² + (2/15)²×3² = (16+36)/225 = 52/225，σ_g = 0.4807401701；β = 1/0.4807401701 = 2.0801257358；
  Pf = Φ(−2.08013) = 1.87570%（页面用 A&S 近似算出 1.87569%，显示 1.876%）。
- FORM 不随写法变，仍是 β = 3.000、Pf = 0.134990%——因为两个写法的零集都是 R = S。
- 若拿 R−S 的精确值当基准，R/S−1 的 MVFOSM 误差是 +1289.5%。

### 9.2 主例题的比值写法

同一失效面写成 g₂ = X₁²/(2X₂) − 1 时（MVFOSM 在均值点展开）：

- g₂(μ) = 100/40 − 1 = 1.5
- ∂g₂/∂X₁ = X₁/X₂ = 0.5，∂g₂/∂X₂ = −X₁²/(2X₂²) = −0.125
- σ_g = 0.875，β = 1.5/0.875 = **1.7142857143**
- Pf = Φ(−1.71429) = **4.32381%**（页面显示 4.324%）
- 而 FORM 仍是 β = 2.10834、Pf = 1.75008%

这正是“MVFOSM 的 β 依赖 g 的代数写法、验算点法不变”的主例题版本。

### 12.3 页面（JS）与 Python 基准的末位差异

两条独立实现，差异都来自“Φ 的近似”和“HLRF 精修”，不影响显示：

| 量 | Python | 页面 JS | 绝对差 |
|---|---|---|---|
| MVFOSM Pf | 0.0480461647 | 0.0480461435 | 2.1×10⁻⁸ |
| FORM Pf | 0.0175008089 | 0.0175007467 | 6.2×10⁻⁸ |
| SORM Pf | 0.0164708180 | 0.0164707643 | 5.4×10⁻⁸ |
| R/S−1 MVFOSM Pf | 0.0187570008 | 0.0187569356 | 6.5×10⁻⁸ |
| 精确 Pf | 0.0162262963 | 0.0162263005 | 4.2×10⁻⁹ |
| FORM β | 2.1083396823 | 2.1083396826 | 3×10⁻¹⁰ |
| SORM κ | 0.0611756786 | 0.0611753654 | 3.1×10⁻⁷ |

原因：

1. 页面 `math.js` 用 Abramowitz–Stegun 26.2.17 近似 Φ（绝对误差 < 7.5×10⁻⁸），Python 用 `math.erf`；所有 Pf 的差异都 ≤ 7×10⁻⁸。
2. 页面 HLRF 收敛后再做最多 6 步精修，所以 u*、x* 末位与 Python 差 10⁻⁵～10⁻⁴，β 只差 10⁻¹⁰。
3. SORM 的 κ 由设计点算 Hessian 投影，设计点末位差异传递为 κ 的 3×10⁻⁷ 差异。

结论：**3 位小数的显示值两套实现完全一致**；自检的各类容差（10⁻¹²～10⁻⁵）覆盖上述差异。

### 12.4 站台 9 切线误差案例（β=2.108，κ=0.5）

U 空间标准正态、同一设计点 `(β,0)`，比较四种失效域：

| 失效域 | Pf | 等效 β | Pf 相对线性 | β 误差 |
|---|---:|---:|---:|---:|
| 线性（半空间 `u1>β`） | 1.752% | 2.108 | 0.0% | 0.000 |
| 凸（`u1>β+κu2²/2`） | 1.154% | 2.272 | −34.1% | +0.164 |
| 凹（`u1>β−κu2²/2`） | 4.193% | 1.729 | +139.4% | −0.379 |
| 圆外（极端 `r>β`） | 10.841% | 1.235 | +518.9% | −0.873 |

- 线性：`Pf=Φ(−β)`；凸/凹：对 `u2` 做 400 段 Simpson 数值积分 `∫φ(u2)Φ(−(β±κu2²/2))du2`；极端：`Pf=exp(−β²/2)`。
- 极端案例就是“失效域在密度等高线外”，β 仍 2.108，但 Pf 从 1.752% 变成 10.841%，等效 β 只有 1.235——直线切线把 Pf 低估约 6.2 倍。
- 页面实现：`src/js/model.js` 的 `tangentErrorCase(beta,kappa)`；交互在站台 9 的 β/κ 滑块。
