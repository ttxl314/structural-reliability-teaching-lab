## 0. 一页速览

**做什么**：一个**单文件、离线、双击即开**的 HTML 教学页。围绕主例题

```
g(X) = X1² − 2X2
X1 ~ N(10, 2),  X2 ~ N(20, 5),  ρ12 = 0.5
```

把 **均值点法（MVFOSM / 中心点法）→ 验算点法（FORM / HLRF）→ 二阶法（SORM / Breitung）→ 蒙特卡洛（MC）** 放在同一组联动视图里：左边 X 空间、右边 U 空间，下面迭代表 / 收敛图，右边结果与公式。改一个参数，几种方法的结果同时变；按“单步”，HLRF 的切线、垂足、验算点一步一步长出来。

**为什么**：过去两天已有 8 张图（U 空间、β 距离、Cholesky/PCA、线性化误差、形式敏感、HLRF、ρ 影响、半空间 vs 圆），每张讲一个点，但都是静态的、分开的。课上换方法要翻页，改参数看不到联动，学生很难把“同一道题的不同 β/Pf”与“不同算法”连起来。这个页面把它们串成一张**实验台**：不是替代 PPT，而是 PPT 里随时切进去的演示。

**给谁用**：JCSS 2026 / 研究生 / 工程师课堂；教师投屏操作，学生看大屏；也可课后自学。

**关键数字（已用 Python 独立核算）**：

## 2. 教学目标与 45 分钟节奏

**学完能回答**：

- 为什么 β 要在 U 空间里定义？“最近”为什么等于“最可能失效”？
- 均值点法、验算点法、二阶法、蒙特卡洛分别做了什么假设？误差从哪来？
- 同一个失效面，为什么换个代数写法 β 会变？哪种方法不变？
- β=2.108 时，Pf 为什么可以是 1.75%，也可以是 10.83%？（半空间 vs 圆）
- 什么时候必须上模拟？模拟的误差怎么估计？

**三句话总结**（页面结尾）：

1. 去 U 空间：把“最可能失效”变成“离原点最近”。
2. FORM：在最可能失效点（验算点）线性化，β 就是最近距离，Pf ≈ Φ(−β)。
3. 误差来自线性化和边界形状：SORM 加曲率修正，MC 用大样本做基准；MVFOSM 的 β 随 g 的写法变，FORM 不变。

**45 分钟建议节奏**：

| 时间 | 站台 | 教师动作 | 学生看到 |
|---|---|---|---|
| 0–3 min | 0 总览 | 先给五个数：4.80 / 1.75 / 1.65 / 1.62% | 同一道题，答案差 3 倍 |
| 3–10 | 1 变量与 U 空间 | 拖 ρ、切 Cholesky/PCA | 椭圆 → 圆，β = 距离 |
| 10–18 | 2 均值点法 | 显示均值点切线；换 g 的写法 | β 从 1.664 变 1.714 / 2.080 |
| 18–30 | 3 FORM / HLRF | 单步 6 次；指 α | 切线 → 垂足 → 验算点 |
| 30–36 | 4 SORM | 放大曲率；对比 1.750 → 1.647 | 曲率修正很小但有效 |
| 36–42 | 5 MC | 抽 10 万点；看 CI | 1.628% ± 0.012%，验证 FORM |
| 42–45 | 6 公式卡 | 收三句话 | 一页公式 + 对比表 |

> 若这一节只有 45 分钟，建议**站台 0–4 必讲，站台 5 快速演示，站台 6 留给课后**；页面支持直接跳站，不按顺序也不乱。

### 3.3 关于“要不要做一个软件”

您提到“单独 HTML 不好弄就做一个软件，用 HTML 显示”。我的判断是：**这道题不需要后端，单文件 HTML 反而更适合教室**。

- 本题是 2 维、正态、解析 g；HLRF 一次不到 1 ms，10 万次 MC 在浏览器里约几十 ms，完全算得动。
- 单文件 HTML：不用装 Python、不用起服务、不怕断网、不怕教室电脑权限限制；双击就开，U 盘拷走就能用。
- 只有两种情况才需要“软件 + 后端”：① 课上要**现场输入任意 g(x)**；② 要算 **3 维以上 / 非正态 / 子集模拟**。这两种可以放到 v2，用同一个前端加一个 Python 计算服务，不影响 v1。
- 所以 v1 建议就做**单文件 HTML**；体验上它已经是一个小软件，只是没有安装包。

## 4. 主例题与基准答案

### 4.1 题目

- 功能函数：`g(X) = X1² − 2X2`
- 极限状态面：`X2 = X1² / 2`（抛物线）
- 失效域：`g < 0`，即 `X2 > X1² / 2`（抛物线上方）
- 随机变量：`X1 ~ N(10, 2)`，`X2 ~ N(20, 5)`，`ρ12 = 0.5`
- 协方差：`C = [[4, 5], [5, 25]]`；Cholesky：`L = [[2, 0], [2.5, √18.75]]`
- 均值点：`μ = (10, 20)`；`g(μ) = 60`（安全）

### 4.2 基准表（页面所有数字的唯一真源）

| 方法 | β | Pf | 可靠度 | 关键点 / 备注 |
|---|---:|---:|---:|---|
| MVFOSM（均值点法） | 1.6641 | 4.8046% | 95.1954% | 切线在均值点；`U_L=(−1.6154, 0.3997)`，`X_L=(6.7692, 17.6923)` |
| FORM（验算点法） | 2.10834 | 1.75008% | 98.24992% | HLRF 6 步；`U*=(−1.92808, 0.85299)`，`X*=(6.14384, 18.87337)` |
| SORM（Breitung） | 2.10834 | 1.64708% | 98.35292% | `κ=0.061176`，`βκ=0.128979`，修正因子 `0.94122` |
| MC（N=4×10⁶） | — | 1.62803% | 98.37197% | 失效 65,121 个；`se=0.00633%`；95% CI ±0.0124% |
| 精确（一维条件积分） | — | 1.62263% | 98.37737% | 基准；不是课堂手算，只作“真值”参考 |
| χ² 圆（另一边界形状，仅对照） | 2.10834 | 10.8333% | 89.1667% | `exp(−β²/2)`；说明“β 相同、边界不同，Pf 不同” |

> 显示约定：β 保留 3 位小数（2.108），Pf 大卡保留 2 位小数（1.75%），表格保留 3 位有效数字（1.750%）。四舍五入后必须与现有图一致：1.664 / 2.108 / 4.80% / 1.75%。

### 4.3 关键中间量（课上会被问到的数）

| 量 | 值 | 说明 |
|---|---|---|
| `∇g(μ)` | `(20, −2)` | 均值点梯度 |
| `σ_g` | 36.0555 | `√(∇g^T C ∇g)`；交叉项 −400，使 σ_g 从 √1700=41.23 降到 36.06 |
| `U_L` | `(−1.61538, 0.39970)` | 均值点切线的垂足；也是 HLRF 第 1 步 |
| `U*` | `(−1.92808, 0.85299)` | 验算点；`β=‖U*‖=2.10834` |
| `X*` | `(6.14384, 18.87337)` | `X* = μ + L U*`；`g(X*)≈0` |
| `α` | `(−0.91450, 0.40458)` | 方向余弦；`α = U*/β` |
| `α²` | `(0.83631, 0.16369)` | X1 贡献 83.6%，X2 贡献 16.4% |
| `κ` | `0.061176` | 主曲率（n=2 只有一个）；`1/κ≈16.35` |
| `∂β/∂μ1` | `0.57404` | 相关正态：`∇ₓg/‖Lᵀ∇ₓg‖`；ρ=0 时才等于 `−α1/σ1` |
| `∂β/∂μ2` | `−0.09343` | 同上；注意相关时的值不是 −0.081 |

| Pf | 6.744% | 4.298% | 2.757% | 1.750% | 0.4465% |

### 4.4 数值口径

- 内部用 double；HLRF 收敛 `|g|<1e-8`，最多 30 步；SORM 曲率用解析 Hessian，并用有限差分交叉校核。
- MC 用固定种子（默认 `20261119`），同一种子可复现；页面显示 N、失效数、COV、95% CI。
- 公式里的 Φ 用高精度正态 CDF（与 Python `math.erf` 对齐到 1e-8 以内）。
- 单一真源：`reference_values.py`；页面 `?selftest=1` 自动比对上面所有数字，失败则红条提示。
- **所有“方法结果”都必须由页面当场算出**，不能写死；只有“精确值 1.623%”和 MC 参考值可以预置（并标明来源）。

### 5.3 逐站说明

#### 站台 0 · 总览：同一道题，五个答案

- **屏上**：5 张方法卡（每张显示 β、Pf、R），一条 log 轴 Pf 对比条（MVFOSM / FORM / SORM / MC / 精确），一张“方法地图”（X → U → 线性化 → 设计点 → 曲率 → 模拟），一个“一键跑完”按钮。
- **交互**：点任意卡片跳到对应站台；“一键跑完”按顺序高亮四种方法，最后停在对比表；hover 卡片时在对比条上高亮对应柱。
- **讲解**：先制造冲突——同一道题，4.80% vs 1.75% vs 1.62%，谁对？为什么？不急着解释，带进站台 1。
- **公式**：`Pf=Φ(−β)`、`β=−Φ⁻¹(Pf)`（只作为“换算”，不是定义）。
- **备注**：大数字卡同时显示 β、Pf、R，避免学生把“β 大”与“可靠度大”搞混。

#### 站台 1 · 变量与 U 空间：为什么“最近”等于“最可能”

- **屏上**：X 空间（均值、1/2/3σ 椭圆、极限状态面、失效区）；U 空间（同心圆、变换后的曲线、设计点）；下方矩阵 L 与 QΛQᵀ 的小卡片。
- **交互**：μ1/μ2/σ1/σ2/ρ 滑块；Cholesky/PCA 切换；`ρ=0` 按钮；`显示 1/2/3σ 椭圆` 开关；拖动均值（P1）。
- **讲解**：X 空间里“离均值近”不等于“概率密度大”（椭圆是斜的）；U 空间把等概率线变成圆，概率密度只跟半径有关，所以“最近”=“最可能”。
- **公式**：`U=L⁻¹(X−μ)`，`X=μ+LU`；等概率椭圆 `(x−μ)ᵀC⁻¹(x−μ)=β²`；Cholesky 与特征分解只差一个正交旋转。
- **关键数字**：`L=[[2,0],[2.5,4.3301]]`；同一个验算点在 Cholesky 下 `U*=(−1.928,0.853)`，在 PCA 下 `(−0.381,2.074)`，β 都是 2.108。
- **常见问题**：为什么不用 X 空间的欧氏距离？因为 X 的分量单位、方差、相关性都不同，距离没有概率意义。

#### 站台 2 · 均值点法（MVFOSM）：最简单，也最容易被“写法”骗

- **屏上**：均值点、切线、原点到切线的垂足、β_M；右下角“真实曲线 vs 切线”的误差阴影；一个“换写法”开关。
- **交互**：显示/隐藏切线；`g1 vs g2` 切换；`非线性程度` 滑块（P1）；“显示垂足”开关。
- **讲解**：只在均值点取一阶泰勒，β=μ_g/σ_g；对线性 g、正态 X 是精确的；对非线性 g，切线离验算点远，误差大；更糟的是换个代数写法，β 就变——这不是数值误差，是方法本身不具有不变性。
- **公式**：`g≈g(μ)+∇g(μ)ᵀ(X−μ)`；`μ_g≈g(μ)`；`σ_g²≈∇gᵀC∇g`；`β_M=μ_g/σ_g`；`Pf≈Φ(−β_M)`。
- **关键数字**：`μ_g=60`，`σ_g=36.056`，`β=1.664`，`Pf=4.805%`；交叉项 −400 使 σ_g 从 41.23 降到 36.06（ρ=0.5 的效应）。
- **形式敏感性（必讲）**：
  - 主例题的等价写法 `g2 = X1²/(2X2) − 1`（X2>0 时与抛物线同解）：MVFOSM `β=1.714`（Pf=4.324%），FORM 仍是 `β=2.108`。
  - 经典小例 `R~N(30,4)`、`S~N(15,3)`：`g1=R−S` 的 MVFOSM `β=3.000`（Pf=0.135%）；`g2=R/S−1` 的 MVFOSM `β=2.080`（Pf=1.876%）；FORM 两者都是 3.000。
  - 建议课上用 `R/S−1`，差异大、结论干净；主例题的 1.714 作为“同一道题也能变”的补充。
- **常见问题**：为什么 ρ>0 反而让 β 变大？因为 `∂g/∂X1` 与 `∂g/∂X2` 异号，正相关让两项“抵消”，σ_g 变小。

#### 站台 3 · FORM/HLRF：在验算点线性化

- **屏上**：U 空间大图；当前迭代点 `U_k`、切线、原点到切线的垂足 `U_{k+1}`、轨迹；右侧迭代表（k, u1, u2, β, g, α）；下方 β_k 与 |g| 收敛小图。
- **交互**：重置 / 单步 / 播放 / 速度；点迭代表任意一行回放该步；“显示切线/垂足/轨迹”开关；“从不同起点”（P2）。
- **讲解**：HLRF 的每一步就是“在当前点取切线，再取原点到切线的垂足”；第 1 步的垂足正好是均值点法的 `U_L`（β=1.664），第 2 步 2.090，第 3 步 2.1083，之后几乎不变；收敛后切线在验算点，β 是最近距离。
- **公式**：`β=min‖u‖ s.t. g(u)=0`；`u*=βα`；`α=−∇g(u*)/‖∇g(u*)‖`；`u_{k+1}=[(∇g(u_k)ᵀu_k−g(u_k))/‖∇g(u_k)‖²]∇g(u_k)`；`Pf≈Φ(−β)`。
- **关键数字**：6 次迭代；`U*=(−1.928,0.853)`；`X*=(6.144,18.873)`；`α=(−0.9145,0.4046)`，`α²=(83.6%,16.4%)`；`β=2.108`，`Pf=1.750%`。
- **常见问题**：为什么第 1 步是均值点法？因为从 `U=0` 出发，切线就是均值点切线，垂足就是 `U_L`；所以 MVFOSM 可以看作 HLRF 的第 1 步。
- **常见问题**：α 是什么？是验算点处极限状态面的法向余弦，`α_i²` 是变量 i 对 β 的方差贡献；本例 X1 占 83.6%。

#### 站台 4 · SORM：β 不变，Pf 因曲率修正

- **屏上**：`U*` 附近的放大窗（真实曲线、切线、密切抛物线/圆）；κ、βκ、修正因子；FORM/SORM/MC 的 Pf 对比条；误差百分比。
- **交互**：“放大曲率”×1/×2/×5；显示/隐藏密切圆；切换 Breitung/一阶；“回到全图”。
- **讲解**：FORM 只用到一阶梯度，把边界当直线；SORM 再用二阶曲率，把边界当抛物线；本例 `κ=0.0612`，`βκ=0.129`，修正因子 0.941，Pf 从 1.750% 降到 1.647%，离精确 1.623% 只差 1.5%；FORM 差 7.9%。
- **公式**：`Pf≈Φ(−β)∏(1+βκ_i)^(−1/2)`；n=2 时 `Pf≈Φ(−β)/√(1+βκ)`；`κ_i` 为主曲率（安全域外法向为正；κ>0 使失效域变小）。
- **注意**：β 还是 2.108，SORM 没有改 β，只改 Pf 的换算；这说明“β=距离”与“Pf=Φ(−β)”是两件事。
- **常见问题**：为什么 SORM 不重新找验算点？验算点由一阶条件定义，SORM 是在同一点加二阶信息；如果要更准，可以迭代曲率或用精确积分。

#### 站台 5 · 蒙特卡洛：用大样本做基准

- **屏上**：X 空间样本云（安全蓝、失效红），U 空间同一批样本；运行中的 Pf 估计与 95% CI 带；N、失效数、COV、CI 宽度表；与 FORM/SORM/精确线的对比。
- **交互**：批量 1k / 10k / 100k；播放/暂停/重置；固定种子；“在 X/U 空间显示”切换；“显示 FORM 切线”开关；IS 开关（P2）。
- **讲解**：MC 不假设线性化，直接数 `g<0` 的比例；误差 ∝ 1/√N；Pf=1.6% 时，N=10⁴ 只有约 160 个失效样本，COV≈7.8%；N=10⁵ COV≈2.5%；N=4×10⁶ 才到 0.39%。FORM 只算了几十次梯度，就把 Pf 算到 1.75%，这就是“近似换速度”。
- **公式**：`Pf≈(1/N)ΣI[g(x_j)≤0]`；`COV=√((1−Pf)/(N Pf))`；95% CI ≈ `Pf±1.96·se`。
- **关键数字**：N=4×10⁶，失效 65,121，`Pf=1.628%`，`se=0.0063%`，CI ±0.0124%；与精确 1.623% 一致。
- **常见问题**：为什么 MC 的答案每次不一样？因为随机抽样；固定种子可复现；CI 告诉你“不一样”有多大。

#### 站台 6 · 公式卡：一页把方法串起来

- **屏上**：分组公式（基础 / 变换 / MVFOSM / FORM / SORM / MC），每条配“用在哪 / 假设 / 坑”；一张方法对比表（假设、β、Pf、计算量、Pf 相对误差、误差来源）；三句话总结；β↔Pf 换算表。
- **交互**：打印/导出 PDF；“只看公式”/“只看对比表”；字号放大。
- **讲解**：收束——方法没有绝对好坏，只有假设是否匹配、误差是否可接受、计算量是否付得起。
- **公式**：见 §7。
- **课后**：留 2 道思考题（ρ 的影响；半空间 vs 圆）。

## 7. 公式梳理清单

> 页面上的公式按“基础 → 变换 → 四种方法 → 模拟”分组；每条都配一句“什么时候能用/坑在哪”。以下为清单，实现时用构建期预渲染的 SVG（离线、清晰），动态数字用 HTML 变量。

### 7.1 基础

| # | 公式 | 用在哪 | 假设 / 坑 |
|---|---|---|---|
| 1 | `Pf = P[g(X)≤0] = ∫_{g(x)≤0} f_X(x) dx` | 全页 | 定义；多维积分一般算不出来，才需要近似/模拟 |
| 2 | `β = −Φ⁻¹(Pf)`，`Pf = Φ(−β)` | 结果卡、对比表 | β 的几何定义是最近距离；`Pf=Φ(−β)` 只在半空间/线性边界下严格，非线性时是 FORM 近似 |
| 3 | `Φ(−1)=15.87%`，`Φ(−2)=2.28%`，`Φ(−2.108)=1.75%`，`Φ(−3)=0.135%`，`Φ(−4)=3.17×10⁻⁵` | 换算表 | 建议背 2.0 / 3.0 / 4.0 三档 |

### 7.2 变换

| # | 公式 | 用在哪 | 假设 / 坑 |
|---|---|---|---|
| 4 | `U_i=(X_i−μ_i)/σ_i` | 独立正态 | 相关变量不能直接这样标准化 |
| 5 | `X=μ+LU`，`U=L⁻¹(X−μ)`，`LLᵀ=C` | 相关正态 | Cholesky 要求 C 正定；L 下三角 |
| 6 | `X=μ+QΛ^{1/2}U`，`QΛQᵀ=C` | 相关正态（PCA） | 与 Cholesky 差一个正交旋转；β、Pf 不变 |
| 7 | `(x−μ)ᵀC⁻¹(x−μ)=β²` | X 空间等概率椭圆 | 椭圆主轴 = C 的特征向量；不是“圆” |

### 7.3 均值点法（MVFOSM）

| # | 公式 | 用在哪 | 假设 / 坑 |
|---|---|---|---|
| 8 | `g(X)≈g(μ)+∇g(μ)ᵀ(X−μ)` | 站台 2 | 只在均值点展开；非线性强时误差大 |
| 9 | `μ_g≈g(μ)`，`σ_g²≈∇gᵀC∇g` | 站台 2 | 需要 g 在均值点可微；交叉项 `2∂1g∂2gρσ1σ2` 别漏 |
| 10 | `β_M=μ_g/σ_g`，`Pf≈Φ(−β_M)` | 站台 2 | 线性 g + 正态 X 时精确；否则是近似 |
| 11 | 形式敏感性：`g=R−S` vs `g=R/S−1` | 站台 2 | 同一失效面，MVFOSM 的 β 可以差很多；FORM 不变 |

### 7.4 FORM / HLRF

| # | 公式 | 用在哪 | 假设 / 坑 |
|---|---|---|---|
| 12 | `β = min{‖u‖ : g(u)=0}` | 站台 3 | β 的几何定义；U 空间标准正态 |
| 13 | `u* = β α`，`α = −∇g(u*)/‖∇g(u*)‖` | 站台 3 | α 指向验算点；`α_i²` 是方差贡献。教材若把 α 定义为梯度方向，则写 `u*=−βα`，符号相反 |
| 14 | `u_{k+1} = [(∇g(u_k)ᵀu_k − g(u_k))/‖∇g(u_k)‖²] ∇g(u_k)` | 站台 3 | HLRF 迭代；从 U=0 出发第 1 步 = 均值点法 |
| 15 | `x* = μ + L u*`，`g(x*)=0` | 站台 3 | 反变换回物理空间 |
| 16 | `Pf ≈ Φ(−β)` | 站台 3 | 一阶近似；边界弯曲时用 SORM/模拟修正 |
| 17 | `∂β/∂μ = ∇ₓg / ‖Lᵀ∇ₓg‖`；ρ=0 时 `∂β/∂μ_i = −α_i/σ_i` | 站台 3（P1） | 灵敏度；本例 0.574 / −0.093（相关时不能直接用 −α_i/σ_i） |

### 7.5 SORM

| # | 公式 | 用在哪 | 假设 / 坑 |
|---|---|---|---|
| 18 | `Pf ≈ Φ(−β) ∏_{i=1}^{n−1}(1+βκ_i)^(−1/2)` | 站台 4 | Breitung；κ_i 为主曲率，符号约定要讲清（教材若取相反法向，则写成 1−βκ） |

| # | 公式 | 用在哪 | 假设 / 坑 |
|---|---|---|---|
| 21 | `Pf≈(1/N)Σ I[g(x_j)≤0]` | 站台 5 | 无偏；误差 ∝ 1/√N |
| 22 | `COV=√((1−Pf)/(N Pf))`，`se=√(Pf(1−Pf)/N)` | 站台 5 | Pf 很小时需要很大 N |
| 23 | `Pf≈(1/N)Σ I[g(v_j)≤0] f(v_j)/q(v_j)` | 站台 5（P2） | 重要抽样；q 选设计点附近；权重方差决定收益 |
| 24 | 半空间 `Pf=Φ(−β)`；n 维球 `Pf=P(χ²_n>β²)` | 站台 4/6 思考题 | 同样是 β，边界形状不同 Pf 不同；n=2 时 `exp(−β²/2)` |

## 9. 技术方案

### 9.1 形态

- **交付**：`structural-reliability-lab.html`，单文件，双击打开。
- **体积**：目标 < 1.5 MB；公式用内联 SVG，JS/CSS 内联，无外部请求。
- **浏览器**：Chrome / Edge 120+（主），Firefox 120+（备）；不支持 IE。
- **离线**：从 U 盘、桌面、邮件附件打开均可；`file://` 下无模块加载问题（用经典脚本，不用 `type="module"`）。

### 9.2 架构

```
state（例题/参数/站台/迭代步/样本）
   │
   ├─ model.js：g、∇g、Hessian、Cholesky、HLRF、SORM、MC
   ├─ charts.js：X 视图、U 视图、收敛图、样本云（Canvas 2D）
   ├─ stations.js：7 个站台的 render/update
   └─ app.js：状态、路由、快捷键、导入导出
```

- 单向数据流：改 state → 重算 derived → 重绘；不做隐藏的可变状态。
- 每个站台只读 state，不互相调用；站台之间通过 state 联动。
- `CONFIG` 放在文件顶部：例题参数、颜色、标签、参考值；改数字即可换例题。

### 9.3 数值内核（浏览器内）

| 函数 | 方法 | 精度目标 |
|---|---|---|
| `normCdf` | Cody / Hart 双精度算法（不用低精度 erf 近似） | 绝对误差 <1e-10（显示范围内） |
| `normInv` | Acklam 有理逼近 + 一步牛顿修正 | 相对误差 <1e-12 |
| Cholesky / 2×2 特征分解 | 解析式 | 机器精度 |
| HLRF | 解析梯度；`abs(g)<1e-8`，最多 30 步 | 与 Python 基准差 <1e-8 |
| SORM 曲率 | 解析 Hessian + 有限差分校核 | κ 差 <1e-6 |
| MC | mulberry32 种子 + Box-Muller；Cholesky 相关 | 可复现；与 Python 同种子不必逐点一致，统计一致 |
| 正态随机数 | Box-Muller（缓存第二个） | 足够 |

### 9.4 性能

- 滑块输入：重算 + 重绘 < 50 ms；HLRF < 1 ms；SORM < 1 ms。
- MC：每帧 5,000–10,000 个样本，10 万样本约 1–2 s 动画；上限 20 万（再大用预置参考值）。
- Canvas 用 `devicePixelRatio` 缩放，保证投影清晰；样本点超过 2 万时用半透明聚合/抽稀绘制。
- 所有动画用 `requestAnimationFrame`；页面隐藏时暂停。

### 9.5 构建与源码

- 开发用 `src/`（HTML/CSS/JS 分开，便于改），构建脚本把 CSS/JS/SVG 内联成 `dist/structural-reliability-lab.html`。
- 构建脚本用 Python（标准库即可），不引入 npm 依赖；公式 SVG 可预先生成后放进 `src/formulas/`。
- 交付时同时给 `src/` 和 `dist/`：您以后改例题/文字，改 `src` 再跑一次构建即可；上课只用 `dist` 单文件。

### 9.6 扩展性

- 新增例题：在 `CONFIG.examples` 加一项（g、grad、hessian、x 范围、失效区判断、参考值），站台自动适配。
- 新增方法：在 `model.js` 加一个 `computeXxx(state)`，在对比表/站台注册；不必改视图。
- 任意 g(x)（P2）：用安全表达式解析 + 中心差分求梯度/Hessian；仍可复用 HLRF/SORM/MC。
- 非正态（P2）：加 `equivalentNormal(x, dist)`，HLRF 每步更新等效均值/标准差。

### 9.7 测试

- **数值自检**：`?selftest=1` 跑 20 条断言（Φ、Cholesky、HLRF、SORM、MC 固定种子），全绿才显示“可上课”。

## 附录 C · 一处需要核对的口径：`mvfosm_two_forms_comparison.png`

这张图的标题是“同一个抛物线，两种 MVFOSM 线性化”，但图中第二条线 `g2: X2=4X1+10` 与抛物线 `X2=X1²/2` **并不同解**：

- 抛物线过 `(10,50)`，`g2` 线也过 `(10,50)`；
- 但在 `X1=6` 处，抛物线 `X2=18`，`g2` 线 `X2=34`，两条边界差得很远；
- `g2` 线也不是抛物线在任意点的切线（切线斜率 = `X1`，`g2` 斜率 4 对应 `X1=4` 的切线是 `X2=4X1−8`，不是 `+10`）。

所以 `g2` 更像是“另一条线性极限状态”，而不是“同一个抛物线的另一种写法”。如果课上要讲“同一失效面、不同代数写法，MVFOSM 的 β 会变”，更干净的例子是：

- `R~N(30,4)`，`S~N(15,3)`，独立；
- `g1=R−S`：MVFOSM `β=3.000`，Pf=0.135%；
- `g2=R/S−1`：MVFOSM `β=2.080`，Pf=1.876%；
- 两者零集都是 `R=S`；FORM 都是 `β=3.000`，Pf=0.135%。

建议二选一：

1. 把原图 g2 改名为“另一条线性边界”，页面里不声称“同一失效面”；
2. 用 `R−S` / `R/S−1` 重画一张，替换原图（页面站台 2 用新图）。
